# Idea bank: brainstorm (2026-10-09)
 
Output of a 20-agent brainstorm on making the game unique, fun and dynamic. The 300 raw ideas were merged into 226, and three independent judges (systems designer, player and streamer, technical director) scored each one from 1 to 10. These are candidates, not decisions; `claude/game-brief.md` wins where they conflict. Interactive version: https://claude.ai/artifact/5HaHWQL97JBt2q3mSzhKqo
 
Scores: Fun / Unique / Dynamic / Fit / Build. Overall = 0.30 fun + 0.20 unique + 0.20 dynamic + 0.15 fit + 0.15 build. Tiers: S 7.25+, A 6.4+, B 5.4+, C below. "xN" means N agents raised the idea independently.
 
Ideas 227 onward were added later (see "Added after the brainstorm" at the end) and are not scored.
